# Индивидуальное задание по ОПИ

Вариант 20.

Работа состоит из двух частей:

1. Предварительное исследование предметной области: приложение для определения того, что можно приготовить из предложенных ингредиентов.
2. Разработка программы: проверка возможности отображения рекламной заставки на табло.

## Описание программной задачи

Программа проверяет, можно ли отобразить рекламную заставку на прямоугольном табло.

Заставка состоит из символов:

- `R` — красный цвет;
- `G` — зеленый цвет;
- `B` — синий цвет;
- `.` — черный цвет.

Каждая ячейка табло описывается числом от `0` до `7`, которое показывает, какие цвета может отображать эта ячейка.

Черный цвет может отображать любая ячейка табло.

## Структура проекта

- `report.docx` — отчет по индивидуальному заданию;
- `src/main.py` — точка входа программы;
- `src/scoreboard.py` — модуль с логикой проверки табло;
- `tests/test_scoreboard.py` — тесты модуля проверки табло;
- `.gitignore` — список файлов и папок, исключенных из Git;
- `README.md` — краткое описание проекта.

## Запуск программы

```bash
python3 src/main.py
```
