# Индивидуальное задание по ОПИ

Вариант 20.

Тема предварительного исследования: приложение для определения того, что можно приготовить из предложенных ингредиентов.

## Описание

Репозиторий содержит материалы по индивидуальному заданию по курсу «Основы программной инженерии».

На текущем этапе подготовлен первый блок работы: предварительное исследование предметной области.

В отчете рассмотрены цель и задачи программного продукта, существующие аналоги, сравнительный анализ решений, характеристики предполагаемого продукта, жизненный цикл бизнес-процесса, IDEF0-модель и пользователи системы.

## Состав репозитория

- `report.docx` — отчет по первому блоку индивидуального задания;
- `README.md` — краткое описание репозитория.
